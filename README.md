# 安小彪奖励中心

面向幼儿园大班、以小学一年级教材为衔接目标的60天手机端学习、闯关和每日打卡工具。

## 功能

- 60天语文、数学、英语三科学习路线
- 每天语文10题、数学5题、英语5题，完整60天共1200个出题实例
- 语文1道声调、6道字词与拼音互选、3道词语与阅读理解，交替安排昨日和五日回声
- 每日任务、金币、星级和连续打卡
- 家长每日一次“夯”评价，确认孩子整体表现后奖励2枚金币
- 每周成长活动：每天完成作业，以及游泳、街舞、乐高、拼音和两次跳绳
- 课外活动由家长确认，每周最多奖励40金币，不影响每日打卡
- 金币兑换中心、二次确认、彩带兑奖结算和兑换次数记录
- 家长可新增、编辑和删除自定义奖励
- 答错重试与错题记录
- 英语正常及慢速朗读
- 英语自愿录音跟读与回放，可选单词识别（设备支持时）
- 家长设置
- 支持添加到 iPhone 主屏幕和离线打开

## 课程定位

- 语文：按孩子已学的 a o e i u ü、b p m f d t n，逐步加入本周的 l g k h；以看汉字或词语选拼音、看拼音选汉字或词语为主，保留声调练习，取消单独的声母韵母合成与音节拆分题。保留原题库的词语与阅读理解，不自动超前加入其他声母、复韵母或鼻韵母。
- 数学：前10天练20以内不进位、不退位加减，第11～25天加入凑十进位加法，第26天起练20以内加减综合（含退位）；每天穿插分合、数位、比较、规律、顺序、图形和生活应用。
- 英语：降为20个入门词，每个核心词最多连续练2天，前40天完成首次学习，后20天混合复习；前15天两选一，之后逐步三选一，题型轮换避免重复。暂不考拼写、长句翻译和KET难度内容。
- 直接替换原题库，不提供两套课程切换。升级时保留原进度和历史成绩，新练习从热身开始；已完成旧60天的用户会保留历史并进入新一轮。

详细的设计边界和检索来源见 `CURRICULUM_SOURCES.md`。题目均为原创练习，不是教材原文复制。

## 数据与隐私

学习记录、金币、每周活动、奖励设置和兑换记录只保存在当前浏览器中，不会上传到 GitHub。清除浏览器网站数据或删除网页 App 后，这些记录可能丢失。

在同一设备、同一浏览器和同一网址更新网站时，会沿用原来的存储数据。课程升级只迁移课程进度，不重置金币、自定义奖励、兑换次数或兑换历史；自定义奖励和兑换历史不按条数截断。

普通录音回放仅保留在当前题目页面，离开题目、切后台或关闭页面后释放麦克风和录音，不保存为长期记录。录音需在HTTPS正式站点或本地预览中使用，并由使用者主动允许麦克风。

单词识别默认关闭，由家长设置开启后再手动使用。浏览器或设备可能把声音交给自己的联网语音服务处理；识别支持情况取决于设备、网络和权限。显示的100%仅表示识别文本与目标单词一致，不能当作专业发音评分，也不影响金币或每日任务。当前未接入付费发音测评服务。

## 本地预览

使用任意静态文件服务器打开项目根目录即可。项目中的 `server.mjs` 可用于本地预览。
