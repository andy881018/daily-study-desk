# 安小彪奖励中心

面向幼儿园大班、以小学一年级教材为衔接目标的60天手机端学习、闯关和每日打卡工具。

## 功能

- 60天语文、数学、英语三科学习路线
- 每天三科各5题，共900个出题实例
- 昨日回声与五日回声复习
- 每日任务、金币、星级和连续打卡
- 每周成长活动：游泳、街舞、乐高、拼音和两次跳绳
- 课外活动由家长确认，每周最多奖励26金币，不影响每日打卡
- 金币兑换中心、二次确认、兑奖结算和兑换次数记录
- 家长可新增、编辑和删除自定义奖励
- 答错重试与错题记录
- 英语正常及慢速朗读
- 家长设置
- 支持添加到 iPhone 主屏幕和离线打开

## 课程定位

- 语文：按统编版（2024修订）一年级上册顺序，覆盖“我上学了”、识字、三单元汉语拼音和四个后段单元
- 数学：按人教版（2024修订）一年级上册顺序，覆盖5以内和10以内加减、立体图形、11～20、进位加法及复习与关联
- 英语：按北京版（2024）一年级上册六个主题推进，以听说为主，并用Cambridge Pre A1词汇和KET能力做适龄桥接

详细的设计边界和检索来源见 `CURRICULUM_SOURCES.md`。题目均为原创练习，不是教材原文复制。

## 数据与隐私

学习记录、金币、每周活动、奖励设置和兑换记录只保存在当前浏览器中，不会上传到 GitHub。清除浏览器网站数据或删除网页 App 后，这些记录可能丢失。

## 本地预览

使用任意静态文件服务器打开项目根目录即可。项目中的 `server.mjs` 可用于本地预览。
